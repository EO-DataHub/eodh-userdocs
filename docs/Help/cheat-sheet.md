# EODH Cheat Sheet

## 📄 Quick Start Guide
Discover our new **EODH Cheat Sheet** for a double-sided, quick start guide to the data catalogue, processing capability, and integrations.

Download the Cheat Sheet and keep it nearby as a quick reference while exploring, analysing, and processing data on the platform.

**[Download the EODH Cheat Sheet (digital version)](https://eodatahub.org.uk/media/documents/EODH_Cheat_Sheet_Digital_v1.0_2.pdf)**

The Cheat Sheet is a concise and handy resource you can use as quick reference for common useful actions.

It simplifies the data access points and processing capabilities of the Earth Observation Data Hub in one place, capturing everything you need to know to get started.

### 🔎 Data Catalogue
One side focuses on the **Data Catalogue**, including:

* Account setup and getting started
* Workspace management
* Data discovery and search
* Commercial data purchasing
* Quality Assurance (QA) information

### ⚙️ Processing and Integrations

The reverse side introduces the platform's **Processing** capabilities and **Integrations**.

Topics include:

* Getting started with Jupyter Notebooks
* Running workflows
* GIS plugins
* Using `pyeodh`
* Finding additional learning resources and support
