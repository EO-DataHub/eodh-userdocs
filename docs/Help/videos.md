# Tutorial Videos

## EODH YouTube Channel

All tutorial videos for EODH can be found on our dedicated training YouTube channel. Navigate to the relevant playlists to follow short demos to learn about the platform and how to get started. You can also find relevant videos embedded throughout the documentation pages. 

[EODH YouTube ▶️](https://www.youtube.com/@eodatahub){ .md-button }

## User Journeys

User Journeys are long-form video tutorials that demonstrate practical ways to use the Earth Observation Data Hub (EODH). Each journey walks users through common helpful operations step-by-step, helping you to discover useful features, access data, and apply EODH tools with confidence.
